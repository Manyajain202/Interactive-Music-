🎵 Interactive Music Streaming Web Application

A modern, responsive music-streaming web application built with React.js, JavaScript, and Tailwind CSS. It provides an interactive music experience with a music library, audio player, playlists, favorites, search, and recently played tracks.

📌 Project Overview

The Interactive Music Streaming Web Application is designed to deliver a smooth and engaging music experience across desktop and mobile devices. It combines a modern user interface with interactive playback controls and tools for discovering and organizing music.

✨ Features

- 🎧 Interactive Audio Player — Play, pause, seek, adjust volume, and manage the playback queue.
- 🎼 Music Library — Browse songs, artists, and albums.
- 📂 Playlist Management — Organize playlists using browser storage.
- 🔍 Search & Filtering — Search for songs and filter music.
- ❤️ Favorites — Save favorite tracks for quick access.
- 🕘 Recently Played — View recently played songs.
- 📊 User Dashboard — Access music and listening-related sections.
- 📱 Responsive UI — Designed for desktop, tablet, and mobile screens.
- 🧭 Responsive Navigation — Navigate easily between application sections.

🛠️ Tech Stack

- React.js — Component-based UI development.
- JavaScript — Application logic and interactivity.
- Tailwind CSS — Styling and responsive layouts.
- HTML5 Audio API — Browser-based audio playback.
- Browser Storage — Local persistence for supported user data.
- Vite — Development server and production build tool.

🚀 Getting Started

Prerequisites

- Node.js
- npm
- Git

Installation

1. Clone the repository

git clone https://github.com/Manyajain202/Interactive-Music-.git

2. Navigate to the project folder

cd project-2

If your actual folder is named "project 2", use:

cd "project 2"

3. Install dependencies

npm install

4. Start the development server

npm run dev

5. Open the local URL

Visit the URL shown in your terminal, usually "http://localhost:5173".
